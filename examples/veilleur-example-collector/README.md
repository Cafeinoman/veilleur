# veilleur-example-collector

Example collector plugin for [Veilleur](../../README.md): `text_lines` makes one item per non-empty line of a
plain-text file. It is a model to copy, outside Veilleur's package; see the guide
[Writing a collector](../../docs/en/writing-a-collector.md) ([français](../../docs/fr/writing-a-collector.md)).
